# Nerd Point

A Nerd Point é uma loja virtual de produtos geek, animes, games, filmes e séries. O foco principal é apresentar roupas, acessórios e colecionáveis em uma interface moderna, colorida e responsiva.

## Fase 1: Wireframes responsivos

**Vídeo explicativo:**
https://youtu.be/3Y6rppsPp60?si=GDT1iGqq8QttMB8-

### O que foi feito nesta fase
- Criação de wireframes para celular, tablet e computador.
- Planejamento da estrutura visual da página.
- Organização das listagens de produtos em destaque e categorias geek.

### Wireframes
- `docs/wireframe-mobile.png` — mobile, até 767 px.
- `docs/wireframe-tablet.png` — tablet, de 768 px a 1023 px.
- `docs/wireframe-desktop.png` — desktop, a partir de 1024 px.

### Listagens da página
1. **Produtos em destaque:** imagens, nomes, preços e acesso aos detalhes.
2. **Categorias geek:** animes, games, filmes e séries, roupas e colecionáveis.
